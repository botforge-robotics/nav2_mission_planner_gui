# NavPro Mini — Mission Planner GUI

**NavPro Mini** is a cross-platform autonomous mobile robot (AMR) control surface, mission planning, and telemetry application built with Flutter.

Supported Platforms:
- **Android** (Handsets & Tablets)
- **Linux Desktop** (Ubuntu 22.04 / 24.04)
- **Windows Desktop** (Windows 10 / 11)
- **Web (PWA)** (Hosted on GitHub Pages)

## Identity
- **Application Label**: NavPro Mini
- **Android Package**: `com.botforge.navpromini`
- **Current Version**: `v1.0.0`
